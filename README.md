# Amber 微信视频号取件

微信视频号取件扩展的独立发布仓。安装包与 SHA-256 见 Releases 中最新的 `weixin-channels-v*`。

- 应用内「设置 › 插件扩展 › 从 GitHub 安装」读取本仓的 `releases/latest`
- 每个平台下载 `amber-wx-<platform>.zip` 与对应的 `.sha256`
